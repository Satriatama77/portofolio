Fokus & Pendekatan Kerja

Saya adalah lulusan D3 Teknik Informatika dari Politeknik Elektronika Negeri Surabaya (PENS) dengan fokus dan ketertarikan kuat pada arsitektur sistem backend. Selama masa studi dan pengerjaan berbagai proyek, saya terbiasa menangani alur pemrosesan data di balik layar—mulai dari penerimaan request, validasi logika bisnis, hingga penyimpanan dan penarikan data yang efisien.

Dalam pengembangan aplikasi, saya menggunakan PHP dan Python sebagai bahasa backend utama, didukung oleh pengelolaan basis data relasional seperti MySQL dan PostgreSQL. Saya telah mengimplementasikan solusi backend untuk berbagai kebutuhan nyata dan akademik, seperti sistem penanganan pengaduan dengan pemrosesan teks (NLP), platform pengelolaan nilai akademik siswa, hingga perancangan REST API terstruktur untuk integrasi sistem kampus.

Proyek Utama Role: Backend & Database

Sistem Informasi Pengaduan Harga Material Bangunan di Lamongan

Sistem berbasis web untuk memantau, memverifikasi, dan menangani pengaduan disparitas harga material bangunan di wilayah Lamongan. Dilengkapi modul pemrosesan teks (NLP) dan penyediaan data untuk pemetaan spasial.

Masalah (Problem):

Sulitnya memantau selisih harga material antarwilayah secara manual serta kebutuhan memproses dan memvalidasi laporan pengaduan dari masyarakat secara terpusat.

Solusi (Solution):

Membangun backend menggunakan Python dan database MySQL dengan modul pemrosesan data laporan, integrasi NLP, serta penyediaan data katalog harga dan peta disparitas.

Fitur-fitur Sistem:

  • ✓ Sistem Autentikasi & Hak Akses Pengguna (Login)
  • ✓ Modul Pemrosesan Bahasa Alami (NLP) untuk analisis teks laporan
  • ✓ Verifikasi alur status laporan pengaduan
  • ✓ Manajemen data katalog harga material bangunan
  • ✓ Pencatatan pengaduan disparitas harga
  • ✓ Penyediaan data spasial untuk visualisasi peta disparitas

CRUD Kampus (Layanan REST API & PostgreSQL)

Sistem backend untuk menerima, menyimpan, dan menyediakan data entitas kampus melalui antarmuka REST API yang terintegrasi dengan database PostgreSQL.

Masalah (Problem):

Kebutuhan backend terstruktur yang mampu melayani manipulasi data kampus secara konsisten serta terhubung andal dengan database PostgreSQL.

Solusi (Solution):

Merancang endpoint REST API menggunakan PHP dengan query terstruktur ke PostgreSQL untuk menangani seluruh operasi Create, Read, Update, Delete.

Fitur-fitur Sistem:

  • ✓ Endpoint API untuk operasi CRUD data entitas kampus
  • ✓ Integrasi langsung PHP dengan driver basis data PostgreSQL
  • ✓ Penanganan respon terstruktur untuk konsumsi aplikasi klien
  • ✓ Validasi dasar terhadap data masuk sebelum disimpan ke tabel
